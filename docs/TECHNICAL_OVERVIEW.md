# 技術概要・データ設計

このページは、リポジトリの構成と問題データの持ち方をまとめた技術ドキュメントです。

## 使用技術

| 分類 | 技術 |
|---|---|
| UI | Vue 3 |
| フレームワーク | Nuxt 4 |
| 言語 | TypeScript |
| CSS | Tailwind CSS 4、共通CSS |
| 静的ホスティング | GitHub Pages |
| CI/CD | GitHub Actions |
| 音声 | Web Speech API（SpeechSynthesis） |
| ブラウザ保存 | localStorage |
| テスト | Playwright smoke test |
| パッケージ管理 | pnpm |

SSRは無効化したSPA構成です。バックエンド、API、データベース、ログイン機能は現時点では使用していません。

## デプロイ

.github/workflows/deploy-pages.ymlで、mainへのpushをトリガーに以下を実行します。

1. Node.js 22をセットアップ
2. pnpmで依存関係をインストール
3. pnpm generateで静的サイトを生成
4. GitHub Pagesへデプロイ

公開パスはnuxt.config.tsのapp.baseURLで設定しています。

現在の公開URL：

https://toshiakisan1127.github.io/russian-4kyu-training/

## 問題データ

問題データはapp/data/のTypeScriptファイルで管理しています。画面コンポーネントに問題を直接埋め込まず、型付きデータをimportして利用します。

主なファイル：

- questions.ts：前置詞の基本問題
- prepositionPoolV2.ts：前置詞の追加問題
- caseTraining.ts：格変化問題
- verbTraining.ts：動詞問題
- mixedTraining.ts：分野横断問題
- section1.ts〜section8.ts：大問別問題
- readingPassages.ts：朗読テキスト
- vocabulary.ts：語彙データの入口
- vocabularyBulk.ts：語彙574語の一括データ（コア語彙5語を除く）
- vocabularyExamples*.ts：語彙例文

## 語彙データ

語彙は、単語、アクセント付き表記、日本語訳、IPA、品詞、名詞の性・単複・格変化、形容詞の活用、動詞の体・現在形活用、例文と日本語訳などを持ちます。

vocabulary.tsでコア語彙と550語の一括データを結合し、例文を割り当てます。起動時に語彙数、例文数、重複例文、アクセントメタデータを検証します。

## 大問別データ

### 第I問〜第IV問

発音、アクセント、名詞の性・代名詞、名詞の複数形を、それぞれ専用の問題データとして管理します。学習表示では、必要な単語に結合文字のアキュートアクセントを付けます。

### 第V問・格変化

section5.tsの種語、名詞・形容詞の格変化データから問題を生成します。名詞の性、有生・無生、代名詞、形容詞と名詞の一致、正解文の日本語訳、格支配の解説を扱います。

### 第VI問・疑問文への応答

疑問詞ごとに10問のグループを持ち、合計100問です。Natural Responseには、疑問文、アクセント付きの模範応答、模範応答の日本語訳、疑問詞の解説を持たせています。

### 第VII問・人称変化

主語と時制に合う動詞の形を選びます。正解後は完成文、日本語訳、現在形の活用表を表示します。

### 第VIII問・過去形・未来形

主語の性・数に応じた過去形、中性名詞、未来表現などを扱います。完成文と日本語訳、文法解説をデータに保持します。

## 問題生成と出題

多くのトレーニング画面は、問題プールから習熟度を考慮してセッションを作ります。

- 1セッションは原則10問
- new、review、learning、masteredの状態を利用
- 復習対象と新規問題を優先
- 選択肢は出題時にシャッフル
- 回答後に結果をlocalStorageへ記録

問題表示中に読み上げ速度を変更しても、問題セットや回答状態はリセットしない方針です。

## 音声とアクセント

音声はブラウザのSpeechSynthesisを使用します。

- 言語はru-RU
- ロシア語ボイスがあれば優先
- 初期速度は0.4
- 速度は0.1〜1.0
- 表示中のアクセント付きロシア語を読み上げる
- 問題文、完成文、例文など用途に応じたテキストを再生する

アクセント記号は学習者向けの発音補助情報です。ёは文字自体に強勢情報が含まれるため、追加のアキュートを付けない場合があります。

## 学習履歴と設定

ユーザー固有の状態はブラウザのlocalStorageに保存します。

- 問題ごとの正誤・習熟度
- 読み上げ速度
- ダークモード設定

サーバー保存やアカウント間同期はありません。ブラウザのデータを削除すると履歴も失われます。

## 変更時の注意

- 新しい問題にはIDを付け、既存IDを変更しない
- ロシア語の表示文には必要なアクセントを付ける
- 模範文・例文には日本語訳を用意する
- 音声再生に渡す文字列と画面表示を一致させる
- 問題データの追加後はpnpm generateとsmoke testを実行する
- GitHub Pagesのパス変更時はnuxt.config.tsのbaseURLも更新する
