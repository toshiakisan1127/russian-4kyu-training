# SEO Growth Checklist

ロシア語能力検定4級の検索流入を増やすための運用チェックリストです。

## 実装済みの基本対策

- SSG / prerenderで主要ページをJavaScript実行前から読めるHTMLとして配信
- ページ別 title / description / canonical
- ページ別 Open Graph / Twitter Card
- `robots.txt` から `sitemap.xml` を案内
- noindexページ（学習ダッシュボード、フィードバック）をsitemapから除外
- WebSite / WebApplication JSON-LD
- 主要学習ページに LearningResource JSON-LD
- トップと試験説明ページに、利用者にも役立つ4級対策本文と内部リンクを追加
- favicon / OGP画像を静的配信

## デプロイ後にSearch Consoleで行うこと

1. `russian4kyu-training.com` を Google Search Console のドメインプロパティとして登録する。
2. DNS TXTで所有権確認を行う。
3. `https://russian4kyu-training.com/sitemap.xml` を送信する。
4. URL検査で次の主要ページを確認し、未登録ならインデックス登録をリクエストする。
   - `/`
   - `/about`
   - `/mock`
   - `/vocabulary`
   - `/verbs`
   - `/cases`
   - `/prepositions`
   - `/translations/ru-ja`
   - `/translations/ja-ru`
5. 「ページのインデックス登録」で、クロール済み未登録・重複canonical・404などを定期確認する。
6. 「検索パフォーマンス」で検索クエリ、表示回数、CTR、掲載順位を確認する。

## 狙う検索意図

単語を不自然に詰め込まず、それぞれのページ内容に合う検索意図を狙う。

- トップ: `ロシア語 4級`, `ロシア語能力検定 4級`, `ロシア語 4級 対策`
- `/about`: `ロシア語能力検定 4級 とは`, `ロシア語 4級 勉強法`
- `/mock`: `ロシア語 4級 模試`, `ロシア語能力検定 4級 模擬試験`
- `/vocabulary`: `ロシア語 4級 単語`, `ロシア語 4級 語彙`
- `/verbs`: `ロシア語 4級 動詞`, `ロシア語 動詞 活用 練習`
- `/cases`: `ロシア語 4級 格変化`, `ロシア語 格変化 練習`
- `/prepositions`: `ロシア語 4級 前置詞`, `ロシア語 前置詞 格支配`
- 翻訳ページ: `ロシア語 4級 露文和訳`, `ロシア語 4級 和文露訳`

## 外部評価を増やすときのルール

- GitHub READMEなど、自分で管理する関連ページから本番URLへ自然にリンクする。
- 学習記録や開発記事を書く場合は、本当に内容が関係する記事からだけリンクする。
- 相互リンク集、リンク購入、大量の自作サイトからのリンク、コメント欄への宣伝投稿は行わない。
- 公式サイトや他教材の文章をコピーして検索流入用コンテンツにしない。
- 公式過去問そのものを転載せず、オリジナル問題と独自解説を中心にする。
- 「公式」「公認」など、運営元と誤認される表現を使わない。

## 改善サイクル

検索順位はデプロイ直後には確定しない。Search Consoleで実際のクエリを見て、表示回数はあるがCTRが低いページはtitle / descriptionを改善し、順位が付くが内容不足の検索語には既存ページの本文を追記する。

新しいページを増やす場合は、既存ページと検索意図が重複しないこと、独立して利用価値があることを条件にする。検索語だけを変えた薄いページは作らない。
