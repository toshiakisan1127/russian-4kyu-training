# Russian Language Study App

ロシア語能力検定4級の対策を目的とした、ブラウザベースの学習アプリ構想。

## 目的

単語帳を眺めて暗記するのではなく、**4級で出題されそうな問題をテンポよく解き、解説を読んで復習する**ことを中心にする。

大学などで一度ロシア語文法を学んだ人が、忘れている語彙や文法を問題演習の中で思い出す用途を想定する。

## 基本UX

- 1画面1問
- 回答後すぐに正解・解説を表示
- 「次へ」でテンポよく進む
- 正解だけでなく、**不正解の選択肢がどんな場面で使われるかも解説する**
- 間違えた問題は再出題できるようにする
- 学習履歴は当初 `localStorage` に保存

## 問題形式

### 1. 文法問題

四択・穴埋めを中心にする。

対象例：

- 名詞の性・単複
- 6格の基本変化と用法
- 形容詞の一致
- 人称代名詞
- 動詞の現在形・過去形
- 不完了体 / 完了体
- 移動動詞
- 前置詞
- 疑問詞
- 数詞・時刻・日付
- 否定文
- 接続詞
- 命令形

#### 解説方針

例：

> Я живу ___ Москве.
>
> 1. в  
> 2. на  
> 3. из  
> 4. к

正解：`в`

- `в + 前置格`：都市など「〜に / 〜で」
- `на + 前置格`：`на работе`、`на стадионе` など
- `из + 生格`：「〜から / 〜の中から」
- `к + 与格`：「〜のところへ / 〜に向かって」

このように、**1問で関連する複数の文法事項を復習できる解説**にする。

### 2. 露文和訳

ロシア語文を表示し、自分で日本語訳を考えてから模範訳を表示する。

表示内容：

- 模範訳
- 重要単語
- 格や活用の説明
- 文の構造・語順のポイント

### 3. 和文露訳

日本語文を表示し、入力欄にロシア語を書く。

完全自動採点は行わず、**自己採点方式**を基本とする。

回答後に表示する内容：

- 模範解答
- 別解
- 文法上のチェックポイント
- `○ / △ / ×` の自己評価

例：

> 私はモスクワに住んでいます。

模範解答：

`Я живу в Москве.`

チェックポイント：

- `жить → живу`
- 場所なので `в + 前置格`
- `Москва → Москве`

### 4. 朗読・アクセント

- ロシア語文を表示
- アクセント付き表記を確認できる
- ブラウザの音声読み上げなどを利用して発音を確認する

## 学習モード

### 分野別練習

苦手なテーマを選んで集中的に解く。

例：

- 前置詞
- 名詞の格変化
- 動詞活用
- 移動動詞
- 和文露訳

### ランダム練習

文法・語彙・和訳・露訳を混ぜて出題する。

### 模試モード

ロシア語能力検定4級の出題形式を意識し、大問単位で問題を並べる。

## 問題データ

問題はアプリ本体から分離し、JSON / TypeScriptデータとして管理する。

イメージ：

```json
{
  "id": "prep-001",
  "type": "multiple_choice",
  "category": "preposition",
  "question": "Я живу ___ Москве.",
  "choices": ["в", "на", "из", "к"],
  "answer": "в",
  "explanation": {
    "correct": "в + 前置格で、都市などにいることを表す。",
    "others": {
      "на": "場所によって『〜で』を表す。例: на работе",
      "из": "生格を取り『〜から』を表す。",
      "к": "与格を取り『〜のところへ』を表す。"
    }
  }
}
```

## 初期アーキテクチャ

まずはバックエンドを持たない静的Webアプリとして作る。

```text
GitHub
  ↓
GitHub Actions / local build
  ↓
S3 Static Website Hosting
  ↓
Browser
```

- 問題データ：ビルド成果物に含める
- 学習履歴：`localStorage`
- DBなし
- ログインなし
- APIなし

必要になった時点で、CloudFront、Cognito、API、DynamoDBなどを追加検討する。

## 最初の目標

まずは小さく以下を作る。

1. 文法四択 20〜30問
2. 和文露訳 10問
3. 露文和訳 10問
4. 回答 → 解説 → 次の問題、の基本UI
5. `○ / △ / ×` の学習記録
6. 間違えた問題の再出題

ここまで作って実際に使い、続けられそうなら問題数を増やす。

## コンテンツ方針

問題数を増やすことより、**1問あたりの解説の質を重視する**。

特に以下を意識する。

- なぜ正解なのか
- なぜ他の選択肢は違うのか
- その選択肢はどんな場面なら正しいのか
- 関連する格・活用・語彙を同時に復習できるか

単語を単独で暗記するのではなく、問題と例文の中で語彙を覚える設計にする。
