# ロシア語4級トレーニング

ロシア語能力検定4級を想定した、ブラウザで使える問題演習アプリです。

## 公開サイト

https://toshiakisan1127.github.io/russian-4kyu-training/

## できること

### 分野別トレーニング

- 前置詞：場所・方向・格支配
- 格変化：生格・与格・対格・造格・前置格
- 動詞：現在形・過去形・未来形・移動動詞・完了体／不完了体
- 語彙：4級向け基本語彙550語
- 総合：前置詞・格変化・動詞・語彙の混合問題

### 大問別問題集

- 第I問：発音
- 第II問：アクセント
- 第III問：名詞の性・代名詞
- 第IV問：名詞の複数形
- 第V問：格変化
- 第VI問：疑問文への応答
- 第VII問：動詞の人称変化
- 第VIII問：過去形・未来形

### その他

- 朗読対策：アクセント付きの読解テキスト、音声、読み方のポイント、日本語訳
- 露文和訳・和文露訳
- 模範文・例文の音声再生
- ロシア語の強勢位置を示すアクセント記号
- 読み上げ速度の調整（0.1〜1.0）
- 正解率と習熟度に応じた出題
- 学習履歴のブラウザ保存
- ダークモード

## 音声

ブラウザの Web Speech API を使ってロシア語を読み上げます。

- 言語：`ru-RU`
- ロシア語音声が利用できる場合はロシア語ボイスを選択
- 初期速度：0.4
- 速度設定：0.1〜1.0
- 表示中のアクセント付きテキストを読み上げに利用

ブラウザや端末によって、利用できる音声・発音・対応状況は異なります。

## データと学習履歴

問題データはTypeScriptで管理し、ビルド時に静的サイトへ組み込みます。サーバー、データベース、ログインは使用していません。

学習履歴や読み上げ速度などの設定は、ブラウザの`localStorage`に保存します。別端末や別ブラウザとは同期されません。

データ構造や出題ロジックは[技術概要](docs/TECHNICAL_OVERVIEW.md)にまとめています。

## 開発

### 必要環境

- Node.js 22以上
- pnpm 11

### セットアップ

```bash
pnpm install
pnpm dev
```

### コマンド

```bash
pnpm dev       # 開発サーバー
pnpm generate  # 静的サイト生成
pnpm build     # 本番ビルド
pnpm preview   # 生成物のプレビュー
pnpm test:smoke
```
